# Gemelo_Digital_TS115

## Descripción en español
Este repositorio presenta el desarrollo de un gemelo digital basado en IoT para el monitoreo predictivo del rendimiento de maquinaria industrial. Su objetivo es integrar datos de sensores, análisis y simulación para anticipar fallas, optimizar la operación y apoyar la toma de decisiones en mantenimiento y producción.

## Description in English
This repository presents the development of an IoT-based digital twin for predictive monitoring of industrial machinery performance. Its goal is to integrate sensor data, analytics, and simulation to anticipate failures, optimize operations, and support maintenance and production decision-making.
